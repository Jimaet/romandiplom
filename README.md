# 🛡️ Онлайн-консультант по информационной безопасности  
**На базе ООО "Бизон Юг", г. Ростов-на-Дону**

> Умный веб-помощник, который быстро и красиво отвечает на вопросы по информационной безопасности, а также помогает сотрудникам через удобный интерфейс и ИИ.

---

## 🚀 О проекте

Данный проект представляет собой современного **онлайн-консультанта**, созданного для **предоставления советов и решений по вопросам информационной безопасности** в компании.

🔒 Разработан на базе организации **ООО "Бизон Юг"**, г. Ростов-на-Дону.  
🧠 Встроен **искусственный интеллект (Yandex GPT)** для живого диалога.  
📱 Адаптирован под **все типы устройств** — от мобильных до десктопов.  
🎨 Имеет **темную стилистику**, **анимации** и **приятный интерфейс**.

---

## 💻 Используемые технологии

| Технология     | Назначение                           |
|----------------|--------------------------------------|
| `HTML5`        | Верстка страниц                      |
| `CSS3`         | Стилизация, анимации, адаптивность   |
| `JavaScript`   | Вся логика взаимодействия            |
| `Yandex GPT`   | Обработка пользовательских запросов  |

---

## 📸 Основной функционал

- 🔍 Поиск по ключевым вопросам (например: *"как сменить пароль в Outlook?"*)
- 💬 Интерактивный ИИ-чат с быстрыми ответами
- 🧠 Работа с API Yandex GPT
- 📂 Поддержка нескольких систем (GLPi, Outlook, Макроскоп и др.)
- 📱 Полностью адаптивный дизайн
- ⚡ Плавные анимации и темная тема
- 🔐 Раздел для проверки надёжности паролей
